# hxwl-05 水族箱换水排程台

由水质监测页扩展的换水排程台: 鱼缸登记、检测资格门禁、每日共享水量额度、执行冻结与修订链。

## 技术栈

React + Vite + TypeScript + CSS (无新增依赖)

## 本地运行

```bash
npm install
npm run dev
```

开发端口: 5105

## 业务规则

| 规则 | 内容 |
| ---- | ---- |
| R1 检测资格 | 鱼缸检测异常后, 必须有时间更晚的合格复测才能排换水; 否则新建/调整/修订均被拒绝, 存量排程进冲突列表 |
| R2 共享额度 | 同一日期所有排程共享 120L 上限; 已执行先计入, 待执行按维护优先级(高→低)抢占; 占用永不超额, 超出部分记缺口 |
| R3 单缸限量 | 单次换水量不得超过登记水量的 50% |

- 调整未执行项: 先释放原额度再按新日期/水量重算, 超额部分进冲突列表。
- 已执行排程冻结: 不可调整/取消, 只能带原因新建修订; 旧版本旧值保留, 额度随修订链转移给新版本。
- 冲突列表逐条列出: 鱼缸、日期、缺口 (L)、触发规则、涉及排程。
- 持久化: localStorage 只存实体 (鱼缸/检测/排程), 额度占用、资格、冲突均为派生值, 刷新后由实体重算, 保证鱼缸、检测、额度占用与修订链一致。

## 代码结构 (数据 / 规则 / 页面分离)

```
src/
  data/           数据层 (不依赖规则与页面)
    types.ts      领域模型: Tank / WaterTest / Schedule / AppState
    ids.ts        顺序 id 生成
    seed.ts       演示种子数据
    store.ts      localStorage 读写与重置
  rules/          规则层 (纯函数, 不触碰存储与页面)
    constants.ts  规则常量: 日上限、单缸比例、优先级权重、判定阈值、规则文案
    tests.ts      检测结论判定 + R1 换水资格
    allocation.ts 每日额度台账、占用预览、R1/R2/R3 冲突检测
    operations.ts 登记/检测/新建/调整/执行/修订/取消, 返回新状态或错误
  App.tsx         页面层: 渲染与交互, 业务判断全部走规则层
```

## 页面功能

- 指标看板: 登记鱼缸数、待执行排程、今日额度占用、未解冲突数
- 鱼缸登记表: 水量、单次上限、维护优先级、最近检测、换水资格
- 登记鱼缸 / 录入检测 (自动判定结论) / 最近检测记录
- 新建排程: 实时预览单缸上限、当日剩余额度与预计缺口
- 每日额度占用: 按占用顺序展示实占/申请/缺口
- 排程列表: 执行 (有冲突禁止)、调整、取消、修订 (内联表单)
- 冲突列表与修订链历史
